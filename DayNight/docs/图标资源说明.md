# 图标资源

## 来源与处理

唯一原稿为 `DayNight/design/daynight-logo.png`。保留日月图形、配色和圆角，不重新绘制。原稿及旧 256 版存在顶部和左边缘的零散白色抠图残留；生成时截取原稿 `(56,70,1140,1132)` 主体区域，垂直居中到 1140 方形坐标，再直接生成每个目标尺寸。此操作去除主体之外的透明留白与残留，避免小图标实际内容缩成约 89%。原稿及旧资源不覆盖。

使用 Windows 自带 System.Drawing 高质量双三次缩放，每帧均由原稿生成，不从其他小尺寸继续缩放；PNG 保留 32 位透明通道。小尺寸为同一 Logo 的缩放版，日月仍可辨认；16 像素无法保留原稿纹理细节。

## 文件与接入

- `DayNight/Assets/daynight.ico`：包含 16、20、24、32、40、48、64、128、256 像素的九个 PNG 压缩帧。项目的 `ApplicationIcon` 指向该文件，用于 EXE。主窗口 `Icon` 与 `TrayIcon.Icon` 同样使用此 ICO，由平台选择尺寸。
- `DayNight/Assets/daynight-{size}.png`：16、20、24、25、30、32、35、40、48、50、60、64、128、256 像素。标题栏显示大小为 20 DIP，100%、125%、150%、175%、200%、250%、300% 缩放分别使用 20、25、30、35、40、50、60 像素。
- `DayNight/Services/AppIconService.cs`：`CreateTitleBarBitmap(RenderScaling)` 返回匹配标题栏缩放的位图。窗口首次附加与 `RenderScaling` 变化时重新取图，替换后释放旧位图；窗口关闭时释放最后一张。该服务不缓存、不持有窗口。
- 原有 `daynight.png` 与模板 `avalonia-logo.ico` 暂留以避免破坏其他引用；新接入不再引用这两个文件。

## 重现与验证

在仓库根目录执行 `pwsh -NoProfile -File scripts/Generate-AppIcons.ps1`。仅依赖 Windows PowerShell/.NET 自带的 System.Drawing，不新增应用依赖。脚本仅写入上述 PNG 与 ICO，不修改桌面设置或启动程序。

本次静态验证读取 ICO 目录，确认九帧尺寸、PNG 签名与每帧 IHDR 宽高一致；检查生成的 256 像素图及 16、20、24、32、40、48 像素原始大小与最近邻放大预览，主体外的顶部散点已经移除，小图标没有额外留白；16 像素的月牙细节受物理像素限制。Debug、Release 构建通过，无错误，保留 OSD 缺少公开无参构造函数的 AVLN3001 警告；该窗口由带参构造函数创建。桌面已检查 100% 缩放下的标题栏图标；其他缩放比例和任务栏、托盘的实际显示尚未逐项验收，资源检查不替代桌面验证。
