# 晨昏线 1.1.2 发布说明

准备日期：2026-11-22。适用于 Windows x64。

## 更新内容

- 修复帮助说明弹窗被长段落撑宽、偏离主窗口的问题，正文自动换行。
- 帮助、未保存计划和关闭选择弹窗统一相对主窗口居中。
- 程序与安装包版本统一为 1.1.2。

## 升级方式

1. 从托盘菜单退出正在运行的晨昏线。
2. 运行 `DayNight-Setup-1.1.2-win-x64.exe`，覆盖安装到原目录。
3. 启动后确认侧栏版本为 1.1.2，并打开“时段规则说明”核对弹窗。

无需卸载旧版，已有计划和设置继续保存在 `%APPDATA%/DayNight/config.json`。
文件夹版需完整解压 `DayNight-1.1.2-win-x64.zip`，运行其中的 `DayNight.exe`，不要仅复制可执行文件。

## 发布附件

- `DayNight-Setup-1.1.2-win-x64.exe`：当前用户安装包。
- `DayNight-1.1.2-win-x64.zip`：包含运行时的文件夹版。
- `SHA256SUMS-1.1.2.txt`：上述两个附件的 SHA-256 校验值。

产物统一位于仓库的 `Setup/Output/`，不纳入源码版本控制。

## 验证范围

- Release 回归测试：87 项通过。
- Windows x64 自包含发布成功。
- Inno Setup 安装包编译成功，程序产品版本为 1.1.2，安装包文件版本为 1.1.2.0；便携压缩包内 243 个文件与发布目录逐一通过 SHA-256 比对。
- 发布目录已检查：包含运行时、使用说明和许可证，不包含 PDB、测试程序集、开发者工具或用户配置；独立代码审查未发现发布阻碍。
- 帮助弹窗在两个主窗口位置均保持 440 DIP 宽度，中心误差为 0；未保存计划和关闭选择弹窗居中且按钮未溢出。此项实测缩放为 100%。
- 保留既有 `AVLN3001` 构建警告，涉及 OSD 窗口没有公共无参构造函数。
- 本轮未执行覆盖安装、真实系统主题切换、多显示器或其他缩放比例实测。
