# 晨昏线（DayNight）需求文档

版本：v1.0（2026-11-18 定稿）
界面原型：`docs\prototype.html`（v0.3，已确认）
本文档为开发依据，代码变更需同步更新本文档。

## 1. 项目概述

晨昏线是一款定时自动切换 Windows 整套主题的桌面工具。用户从 Windows 已安装的主题库（设置 → 个性化 → 选择要应用的主题）中挑选主题，按时间段安排一天的切换计划；到点后程序自动应用对应主题，并提供切换前的屏幕提示、托盘控制与手动干预能力。

**差异化定位**：Windows 11 正在内建深浅色定时切换，但整套主题（壁纸 + 强调色 + 配色 + 声音方案）的定时轮换仍无官方支持，晨昏线填补这一空白。

## 2. 术语

| 术语 | 含义 |
|------|------|
| 整套主题 | Windows `.theme` 文件定义的主题包，含壁纸、强调色、配色、声音方案 |
| 时段 | 一天中从某时刻到下一段起始时刻的区间，绑定一个主题 |
| 切换点 | 某时段的起始时刻，即自动切换发生的时刻 |
| 保持到明天 | 手动选择某主题后跳过今天剩余切换，持续到该时段在明天的结束时刻 |
| OSD | 切换前在屏幕中央弹出的半透明点击穿透提示卡 |

## 3. 需求共识（已与用户逐项确认）

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 切换对象 | 仅整套 `.theme` 主题（系统已装主题库），不做深浅色单独切换 |
| 2 | 空档策略 | 强制全天覆盖：时段首尾相接铺满 00:00–24:00，午夜延续上一时段，直到当天首个起点 |
| 3 | 切换基准 | v1 仅固定时刻；日出日落留作后续版本 |
| 4 | 错过切换 | 启动、开机、从睡眠唤醒时立即对齐当前时段主题 |
| 5 | 日程维度 | v1 单一日程，每天相同 |
| 6 | 主题应用 | 使用 Windows 原生主题管理器静默应用整套主题；必须包含系统和应用明暗、颜色、声音、壁纸等，不能以只改壁纸代替 |
| 7 | 切换前提示 | 居中、无边框、半透明、鼠标点击穿透的 OSD 卡；无按钮；全屏时不弹 |
| 8 | 界面文案 | 不堆说明文字，操作说明收进主窗口标题栏"?"帮助；文案自然、无机器翻译腔 |
| 9 | 文档与素材路径 | 文档在 `DayNight\docs\`，原型 `docs\prototype.html`，美术资产 `DayNight\design\`（2026-11-19 由仓库根目录迁入项目内） |

## 4. 功能需求

### 4.1 主题库
- 扫描系统已安装主题：`%LOCALAPPDATA%\Microsoft\Windows\Themes\**\*.theme` 与 `C:\Windows\Resources\Themes\**\*.theme`
- 主题列表显示名称与壁纸预览缩略图；解析 `.theme`（UTF-16 INI 格式）中的 `Wallpaper=` 获取预览图
- 标记当前使用中的主题（读注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\CurrentTheme`）
- 提供"重新扫描"入口

### 4.2 时段规则（强制全天覆盖）
- 规则为有序段列表 `{起始时刻 HH:mm, 主题}`；段 i 覆盖 `[start_i, start_{i+1})`；每个起点均可编辑；末段延续至次日首个起点
- 编辑时实时校验：时刻严格递增、无重叠；铺满全天为合法状态
- 点开始时间打开双圈时钟。内圈可点选或拖动选择 00 至 23 时，外圈选择 00 至 59 分，正上方为零，顺时针递增。表盘中心同步显示 HH:mm，点“确定”更新草稿，点“取消”或关闭弹层放弃本次拨动。
- 默认浏览计划，点“编辑计划”后可调整时间、主题及增删时段。修改先进入草稿，点击“保存计划”才统一生效；“取消编辑”放弃草稿，保存成功或取消均返回浏览。未保存草稿跨页面保留，退出时可保存、放弃或取消退出。
- 规则页分布条的每个起点均可拖动，按 5 分钟吸附并显示时间；精确到 1 分钟使用选择器。拖动时保留相邻切换点的顺序；表盘可选任意未占用的分钟，确认后按新起点重新排序。
- 至少保留 1 个时段

### 4.3 调度引擎
- 每秒检查切换点；启用提示时提前 N 秒倒计时，到点应用该时段绑定的主题
- 启动、开机、唤醒（`SystemEvents.PowerModeChanged` Resume）时立即对齐当前时段主题
- 全屏时延迟切换：独占全屏、演示模式或前台窗口铺满屏幕时不执行，每秒重新检查，退出全屏后补切；通知忙碌状态本身不作为全屏证据
- 总开关"自动切换"：关闭后暂停全部自动切换与对齐，恢复时立即对齐一次；手动切换不受暂停影响

### 4.4 规则页的调度状态
- 浏览时点击主题名称、缩略图或同一行右侧区域，确认后手动切换整套主题。时间列仅显示时间。点“编辑计划”后，同一行用于修改草稿。
- 规则页显示以下调度状态：

| 标记 | 视觉 | 含义 |
|------|------|------|
| 当前 | 藏青徽章、行高亮 | 正在生效的主题 |
| 已结束 | 行灰化、灰字 | 今天的时段已过去，不会再执行 |
| 下一日 | 藏青字、行正常色 | 今天的执行被跳过，下一日照常自动切换 |
| 无标记 | 正常显示 | 今天的未来时段，到点自动切换 |

- "复位自动调度"按钮：撤销全部手动状态，按当前时刻重新对齐
- 手动状态需持久化，重启后仍生效

### 4.5 切换前 OSD 提示
- 切换前 N 秒（默认 5 秒，可配置 3–10 秒）在屏幕中央弹出自绘提示卡：目标主题名 + 壁纸缩略图 + 倒计时
- 卡片无边框、半透明（Acrylic）、置顶、鼠标点击穿透（`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW`）
- 卡片宽 400 DIP、高度随内容，不显示系统标题栏或大片窗口底色；不抢焦点、不占任务栏，按显示器缩放定位。
- 无按钮；倒计时结束自动执行切换并消失
- 全屏时不弹（与全屏延迟切换联动，退出全屏后再弹再切）
- 通过原生主题管理器静默应用；失败时提示并记录，不主动关闭用户已打开的系统设置窗口

### 4.6 托盘
- 托盘常驻图标（按 Logo 重绘的昼夜盘）；左键打开主界面
- 右键菜单：打开主界面、暂停/恢复调度、跳过本次切换、手动切换到下一时段主题、退出
- 菜单头显示调度状态与下次切换时刻；暂停态图标半透明
- 单实例（命名互斥体）；`--silent` 参数静默启动（仅托盘，不弹主窗口）

### 4.7 自启
- 开机自动启动：写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值为 `exe 路径 --silent`
- 设置页开关控制写入/删除

### 4.7a 主窗口最小化行为（最小化到托盘）
- 设置项"最小化到托盘"（默认开）：
  - 开启：点击最小化按钮 → 主窗口隐藏，驻托盘后台运行
  - 关闭：点击最小化 → 正常最小化到任务栏；点击关闭按钮 → 退出程序
- 关闭按钮始终为退出（不走"关闭即进托盘"的隐式行为），常驻需求由最小化到托盘与开机自启覆盖

### 4.8 设置页
- 外观：应用界面主题（跟随系统 / 亮色 / 暗色），跟随系统时实时响应系统深浅色变化
- 启动：开机自动启动、静默启动、最小化到托盘
- 调度：全屏时延迟切换、启动和唤醒时对齐主题
- 切换提示：OSD 开关、显示时长
- 切换后通知：托盘气泡 + 日志
- 日志：打开日志目录按钮

### 4.9 通知与日志
- 每次切换完成后托盘气泡提示"已切换到「X」主题"
- 日志滚动写入 `%APPDATA%\DayNight\logs\`，记录切换、手动操作、异常

### 4.10 界面
- Avalonia Fluent 风格，中文界面；左侧导航四页：今日时间轴、时段规则、主题库、设置
- 今日时间轴：当前主题卡（时段、下次切换或恢复时刻）+ 24 小时分段色带（当前段高亮、被跳过段弱化标"下一日"）
- 时间轴显示正在执行的已保存计划，规则页编辑草稿明确标识未保存；保存后两页一致。
- 界面图标统一使用 Microsoft Fluent UI System Icons（资产已就位于 `design\fluent-icons\`）
- 应用 Logo：`design\daynight-logo.png`（用户手绘，已定稿）
- EXE、任务栏与托盘使用多帧 ICO；自绘标题栏按显示缩放选择对应像素资源，保留既有 Logo 外观。

## 5. 非功能需求
- 目标系统：Windows 10 / 11，单用户（HKCU），无需管理员权限
- 技术栈：.NET 8 + Avalonia 12.1.4 + CommunityToolkit.Mvvm（用户已建模板项目 `DayNight\`）
- 配置存储：`%APPDATA%\DayNight\config.json`
- 界面文本全部中文；工程标识与代码命名用英文

## 6. 验收清单
- 设 1 分钟后的切换点：OSD 弹出且可穿透点击 → 倒计时结束整套主题应用并核对明暗及强调色 → 气泡通知 → 日志落盘
- 手动切换后：下一时间点跳过（或保持到段尾）、再之后恢复；重启程序手动状态保留
- 全屏播放视频时切换点延迟、不弹 OSD，退出后补切
- 开机自启后 `--silent` 静默驻托盘；错过切换点后启动对齐
- 规则页与时间轴页状态在任何操作后保持一致

## 7. 2026-11-18 修复补充

- 主题库应正确显示 Windows 中文 ANSI 编码的用户主题、本地化内置主题名称和真实壁纸；兼容节不得覆盖主节。非当前的未保存快照不混入已安装主题列表；幻灯片数量按实际存在的条目统计，缺失图片有明确说明。
- 自动切换总开关必须立即保存，退出、重开、启动对齐及唤醒均遵守该开关；暂停期间关闭尚未完成的切换提示，手动操作仍可使用。
- 页面和托盘共用开关状态；主题库重新扫描后同步刷新规则和时间轴的名称与预览。
- 外观继续以已确认 HTML 原型为依据：自绘标题栏、底部状态、统一中文字体与间距、自适应三列主题卡片、规则当前行高亮、小时间带及亮暗色一致性。
- 新增验收：关闭自动切换后退出再开，必须保持暂停；主题库能正确显示“日间主题”，不显示编码字符串；系统主题显示本地化名称；外观选择按钮与当前配色一致。


## 8. 整套主题应用验收补充

- 切换到用户保存的日间主题时，壁纸、系统明暗、应用明暗和强调色应同时符合主题定义；切换深色主题后应恢复对应深色设置。
- 幻灯片主题应启用 Windows 幻灯片模式，声音、光标等由系统主题管理器应用。
- “当前使用”及成功状态必须基于真实应用结果，禁止仅写当前主题路径后宣称完成。应用失败要明确提示，规则页不得提前保存手动保持状态。
- 应用界面的“跟随系统”保持跟随应用明暗模式；显式选择亮色或暗色时仍遵守用户的界面外观设置。

## 9. 自动调度修复验收（2026-11-19）

- 添加时段只拆分末段，不改变已有起点。删除任意起点后，其前一时段自动延续到下一个起点；计划至少保留一段。
- 时间选择必须严格位于相邻起点之间；无效选择保留原值。编辑仅影响草稿。
- 点击保存计划后，清除旧计划的手动状态与待执行提示，并在自动开关开启时立即对齐；关闭状态不被编辑或复位重新开启。
- 旧版本非法配置启动时先备份，再修复非整分钟起点、排序和重复起点，清除失效保持；保留主题绑定、合法切换时间和总开关偏好。
- 定时检查每秒运行。正常切换提前 N 秒提示，到点应用；全屏结束后的补切允许完整倒计时。倒计时与应用任务不得重复入队。暂停、保存新计划、手动应用时取消旧提示，提示结束前再次核对目标与全屏状态。
- “跳过本次”只对当天该次时段有效，不能导致以后每天同一时刻都被跳过。跨过零点仍属同一次时段；末段的真实结束时刻为次日首个起点。
- 保持中明确显示恢复日期时间；重复点击不推迟恢复时间。“复位自动调度”立即撤销保持并重新判定，不等待下一分钟。
- 规则行及行内切换按钮均先说明保持语义并确认，避免无提示进入保持状态。
