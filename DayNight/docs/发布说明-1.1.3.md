# 晨昏线 1.1.3 发布说明

准备日期：2026-11-25。适用于 Windows x64。

## 更新内容

- 修复在主题库点击卡片更换主题后，数秒内被切回计划主题的问题。手动应用的主题保持到当前时段结束，到下一个切换点按计划切换。
- 程序运行期间在 Windows 个性化设置中更换主题，与主题库手动应用同样处理。
- 启动、睡眠唤醒以及程序自身切换主题后的差异仍按对齐处理，错过切换点后的补切不受影响。
- 安装包脚本在发布产物早于 `DayNight.csproj` 时中止编译，避免沿用上一版的版本号和程序。

## 升级方式

1. 从托盘菜单退出正在运行的晨昏线。
2. 运行 `DayNight-Setup-1.1.3-win-x64.exe`，覆盖安装到原目录。
3. 启动后确认侧栏版本为 1.1.3。在主题库点击一张卡片并确认，主题不再被切回，界面显示“手动保持中”。

无需卸载旧版，已有计划和设置继续保存在 `%APPDATA%/DayNight/config.json`。

## 发布附件

本轮尚未打包：只更新了程序版本与文档，没有执行发布和安装包编译。打包时按设计文档第 12 节的顺序执行，产物命名为 `DayNight-Setup-1.1.3-win-x64.exe`。

## 验证范围

- 单元测试：Debug 与 Release 配置各 100 项通过，含 `ManualThemeChangeTests` 新增的 13 项。
- Debug 构建成功，保留既有 `AVLN3001` 构建警告。
- 真机验证在 Debug 构建上完成五项：主题库手动应用、个性化设置更换、到下一个切换点交还计划、启动对齐、暂停期间更换，结果记录在设计文档第 14 节。
- 安装包脚本：在临时目录用 1.1.2 的发布产物验证。发布产物早于项目文件、项目文件缺失两种情况均中止编译；更新发布产物时间后完整编译通过。
- 未执行：真实睡眠唤醒测试、Release 发布、1.1.3 安装包编译和覆盖安装。
